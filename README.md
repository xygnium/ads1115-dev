# ads1115-dev

ADS1115-based thermistor measurement, shared by the Pico (`pico-dev`) and ESP32 (`esp32-dev`) workspaces.

First use: precision glass-bead NTC thermistors, read ratiometrically with pulsed excitation. They serve as the temperature benchmark for the SHT comparison (esp32-dev) and as the attic barrier probes (see esp32-dev/SESSION-SUMMARY-2026-09-22.md, section 6).
